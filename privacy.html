Privacy policy

Effective date: October 14, 2026 · Contact: REPLACE-WITH-YOUR-EMAIL@example.com

This policy describes the current personal Roblox Avatar Uploader project and the intended handling of information if a Pinterest API integration is implemented. The tool is in development; it is not currently a public service.

1. Information processed

The existing local workflow processes avatar image files, Roblox profile links or user identifiers associated with those files, the selected Pinterest board name, and local publishing status/error logs. These files are held on the owner's computer. The website itself is informational and has no account-registration or upload form.

2. Pinterest account access

A future API version would request only permissions necessary for the account owner to create Pins and access relevant boards. The owner would authorize access using Pinterest's supported authorization process. The project should not ask users to disclose their Pinterest password. Any API access tokens must be kept out of this public website and source repository.

3. How information is used

Images and related metadata would be used to prepare Pins, submit authorized publications to Pinterest, and track which files have been published or require review. Information is not intended for sale or advertising profiling.

4. Sharing

When the owner publishes a Pin, the selected image, title, destination board, and any included Roblox profile link are sent to Pinterest and may become visible according to Pinterest's account and board settings. Pinterest handles that information under its own terms and privacy policy. Locally held upload logs are not intentionally transmitted to this website.

5. Storage and retention

The current tool stores image files and CSV status logs locally on the owner's device until the owner deletes them. If an API integration is added, its token-storage and deletion approach must be documented here before public use. This static website does not itself operate a database or application backend.

6. Website hosting

These informational pages may be hosted on GitHub Pages. The hosting provider may process technical request information, such as IP addresses and browser details, to deliver the site. Review the host's privacy statement for those practices. No third-party analytics script or advertising tracker is included in this website's source.

7. Your choices

The owner can stop running the local uploader, delete locally stored images or logs, and manage or remove published Pins through Pinterest. If API authorization is added, authorized access should also be revocable through Pinterest's account settings.

8. Children's privacy

This project is not directed to children and is not intended to collect information from children through this website. Public Roblox profile images or links should be shared only with appropriate permission and in accordance with applicable platform rules.

9. Changes

This policy will be updated if the tool's data practices, public availability, or Pinterest API integration change. The effective date will be updated when material changes are made.
